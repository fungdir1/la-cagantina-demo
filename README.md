# La Cagantina · demo

Nivel 1 · versión 0.6.0-community. Juego arcade de sátira política.

## Jugar

**[Abrir el juego](https://fungdir1.github.io/la-cagantina-demo/)**

Puedes compartir este enlace con los testers. Abre desde el navegador del móvil o del ordenador, sin cuenta de GitHub.

- Móvil: usar el teléfono en vertical y arrastrar el dedo para mover al héroe.
- Ordenador: flechas o WASD; también se puede arrastrar con el ratón.
- Los disparos son automáticos. Los poderes especiales y la pausa tienen botones en pantalla.
- Primero elige la dificultad: Yuma, Normal o Cubano. Después confirma tu nombre.

## Pruebas

Si encuentras un fallo, anota tu dispositivo, navegador, dificultad y en qué momento ocurrió. Una captura o vídeo ayuda a reproducirlo. Puedes reportarlo en [Issues](https://github.com/fungdir1/la-cagantina-demo/issues).

El contador parte de 19.099 kg y guarda tu aporte con una identidad del navegador, independiente del nombre. Mientras el menú indique «GLOBAL PENDIENTE», la cifra incluye la base histórica y tu aporte local; todavía no suma todos los jugadores.

Este repositorio contiene el demo y los recursos necesarios para ejecutarlo.

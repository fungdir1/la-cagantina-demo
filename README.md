# La Cagantina

[Prueba el juego](https://fungdir1.github.io/la-cagantina-demo/?v=0.7.0-two-levels) en móvil o PC.

Versión 0.7.0-two-levels: La Habana y Santiago de Cuba en una misma partida. Tras derrotar a Randy, continúa al nivel 2 desde la pantalla de resultados. El héroe conserva su arma, curitas, especiales y aporte. Los reintentos vuelven al nivel donde ocurrió la derrota.

Controles: arrastra para moverte en móvil; teclado en PC. El disparo es automático. El primer toque habilita el audio según las reglas del navegador.

Este repositorio contiene únicamente la versión jugable y sus recursos. El perfil y el aporte personal se guardan en este navegador; el contador comunitario conserva la configuración de la demo.

Para reportar fallos en [Issues](https://github.com/fungdir1/la-cagantina-demo/issues), indica dispositivo, navegador, dificultad, nivel y momento del fallo. Una captura o vídeo ayuda a reproducirlo.

El contador parte de 19.099 kg. Mientras aparezca «GLOBAL PENDIENTE», suma esa base y el aporte local; todavía no agrega las partidas de todos los testers.
